# Titan PR Writing

泰坦军团（Titan Army）品牌 PR 稿件创作系统 — Claude Code Skill。

为泰坦军团品牌撰写对外 PR 稿件，覆盖八大稿件类型，遵循标准化 6 步创作流程（含信息挖掘环节）。

新文章统一使用 `MMDD【标准标签】标题正文` 命名，例如 `0805【喜报】泰坦军团 G27T8M 斩获第十届 ChinaJoy 黑金奖`。

## 支持的稿件类型

| 类型 | 标签 | 场景 |
|------|------|------|
| 新品发布 | `【电竞新品】` | 新品/新技术/新系列发布 |
| 赛事助阵 | `【赛事直击】`/`【赛事预告】` | 电竞赛事赞助/设备支持 |
| 品牌合作 | `【深度结盟】`/`【重磅合作】`/`【生态共建】`/`【竞逐新程】` | 战略签约/产品指定/生态共建/战队赞助/技术合作 |
| 行业活动 | `【展会直击】`/`【展会预告】` | 参加第三方主办的 B 端大会或 C 端展会 |
| 校园巡展 | `【校园巡展】` | 高校路演/校园巡展 |
| 直播预热 | `【直播预告】` | 直播预告/带货预热/行业对话 |
| 喜报奖项 | `【喜报】` | 市场数据/获奖喜报/渠道表彰 |
| 品牌活动 | `【活动速递】` | 泰坦军团主办或主导的大会、发布会、工厂开放日 |

## 安装

或放入项目的 `.claude/skills/` 目录下。

## 触发方式

发送包含以下关键词的消息即可自动触发：

- "写一篇 PR 稿" / "帮我写新闻稿"
- "新品发布稿" / "赛事直击" / "品牌合作稿"
- "校园巡展稿" / "直播预告稿"
- "喜报" / "展会直击" / "展会预告"
- "泰坦军团活动稿"

也可通过 `/titan-pr-writing` 显式调用。

## 创作流程

1. **选题** — 确定核心主题和稿件类型
2. **信息挖掘** — 对照必备清单，检索缺失信息，列出确认清单给用户逐项确认
3. **搭骨架** — 生成 3 套候选大纲供用户挑选
4. **填内容** — 按行文规范产出正文
5. **自查** — 按 Checklist 逐项核对
6. **定稿** — 保存到对应文件夹

## 迭代优化

用户发回修改版后，AI 自动执行 4 步对比分析（逐句对比 → 差异分类 → 反推风格指南优化 → 输出对比报告），持续优化写作风格。

## 设计原则

- **速查优先**：SKILL.md 内置行文核心规范速查，80% 场景无需加载完整 references
- **按需加载**：边缘规则和完整流程按需翻阅 references
- **规则驱动**：所有声线/句式/词汇/禁忌规则可追溯、可更新
