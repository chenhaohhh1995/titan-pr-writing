# Titan PR Writing

泰坦军团（Titan Army）品牌 PR 稿件创作系统 — Claude Code Skill。

为泰坦军团品牌撰写对外 PR 稿件，覆盖六大稿件类型，遵循标准化 5 步创作流程。

## 支持的稿件类型

| 类型 | 标签 | 场景 |
|------|------|------|
| 新品发布 | `【电竞新品】` | 新品/新技术/新系列发布 |
| 赛事助阵 | `【赛事直击】`/`【赛事预告】` | 电竞赛事赞助/设备支持 |
| 品牌合作 | `【深度结盟】`/`【生态共建】` | 品牌共创/战略合作 |
| 行业活动 | `【展会直击】`/`【展会预告】` | B 端行业大会/峰会参展 |
| 校园巡展 | `【校园巡展】` | 高校路演/校园巡展 |
| 直播预热 | `【直播预告】` | 直播预告/带货预热 |

## 技能结构

```
titan-pr-writing/
├── SKILL.md              ← 主技能文件（路由 + 工作流 + 核心规范）
├── README.md
└── references/
    ├── 项目说明文档.md             ← 5 步标准流程 + 核实规则 + 迭代机制
    ├── 行文措辞说明文档.md          ← 声线/句式/词汇/禁忌清单（写作基准）
    ├── 数据调用说明.md             ← 行业数据源（可选）
    ├── 新品发布-切入策划与大纲规范.md
    ├── 赛事助阵-切入策划与大纲规范.md
    ├── 品牌合作-切入策划与大纲规范.md
    ├── 行业活动-切入策划与大纲规范.md
    ├── 校园巡展-切入策划与大纲规范.md
    └── 直播预热-切入策划与大纲规范.md
```

## 安装

将本目录放入 `~/.claude/skills/` 下即可。

## 触发方式

发送包含以下关键词的消息即可自动触发：

- "写一篇 PR 稿" / "帮我写新闻稿"
- "新品发布稿" / "赛事直击" / "品牌合作稿"
- "校园巡展稿" / "直播预告稿"
- "泰坦军团活动稿"

## 创作流程

1. **选题** — 确定核心主题和稿件类型
2. **搭骨架** — 生成 3 套候选大纲供用户挑选
3. **填内容** — 按行文规范产出正文
4. **自查** — 按 Checklist 逐项核对
5. **定稿** — 保存到对应文件夹

## 迭代优化

用户发回修改版后，AI 自动执行 4 步对比分析（逐句对比 → 差异分类 → 反推风格指南优化 → 输出对比报告），持续优化写作风格。
