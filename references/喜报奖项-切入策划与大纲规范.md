# 喜报奖项 — 切入点策划与大纲规范（骨架）

## 角色设定

你是一位拥有 15 年科技行业报道经验的资深主编，擅长将数据与奖项转化为具有行业公信力的品牌叙事。请以泰坦军团官方账号的笔触撰写。

本类型面向 **市场数据宣告 / 产品获奖 / 渠道合作表彰**场景。叙事面向媒体、行业伙伴、渠道客户、投资者，以第三方权威数据和奖项为核心说服手段。品牌不是"自夸"，而是"被第三方验证过的优秀"。

---

## SEO 策略

核心搜索词：由用户在简报中指定。喜报稿件偏向 **品牌词 + 技术词**（如"MiniLED显示器市占率""QD-OLED获奖""电竞显示器品牌排名"），以数据/奖项关键词驱动搜索流量。

## 文体要求

**必须遵循** `references/行文措辞说明文档.md` 的全部规范，核心要点速查：

- 声线：有数据支撑的权威叙事，自信有力——数据在前，品牌在后，因果自洽
- 词汇：第三方机构全称必须准确、数据年份明确、奖项全称+颁发机构完整
- 句式：数据陈述→品牌表现→因果连接，品牌不"自吹"而"被数据证明"
- 产品：定位 → 核心技术（含具体数字） → 体验叙事（此处可省略品质句——数据本身是品质证明）
- 禁用：空洞形容词（"优秀的""卓越的"等）、未注明来源的数据、弱化词
- 喜报额外强调：**数据引用必须标注来源机构全称**（群智咨询(Sigmaintell)、洛图科技(RUNTO)、IDC 等），数据年份必须明确

## 写作规范

品牌称呼：统一用"泰坦军团"，不简写。

数据引用格式：机构全称 + 数据年份 + 数据内容。示例："据群智咨询（Sigmaintell）数据显示，2025 年全球 OLED 显示器出货量接近 240 万台，同比增长 82%。"

奖项写法：奖项全称 + 颁发机构 + 获奖意义一句话。

产品名格式："品牌 + 型号"，如"泰坦军团 P275MV MAX"。

技术参数写法：数字 + 单位，如"2304 分区""1600 尼特""4K UHD（3840×2160）"。

**数据→品牌的因果链**：每段数据陈述必须紧跟"这意味着品牌什么"，不让数据裸奔。正例："据群智咨询数据显示，泰坦军团以 23.4% 市占率位居第一（数据）→ 彰显了泰坦军团在 MiniLED 领域的绝对领先优势（品牌）"。

## 大纲变体（3 套）

### 变体 A — 数据+奖项驱动型

适用场景：产品获奖 + 市场数据双重亮点。

大纲：
1. 标题 + 副标题（突出数据/奖项核心数字）
2. 行业数据引爆（第三方机构+市场规模+增长态势）
3. 品牌市场表现（市占率/排名+与竞品的对比优势）
4. 奖项宣布（什么奖 + 谁颁的 + 为什么能获奖 + 评审标准 1-2 句）
5. 产品核心技术解析（3-5 段，获奖产品的技术亮点，每段一个技术点）
6. 品牌愿景收束（技术迭代方向+市场承诺）

### 变体 B — 纯数据型

适用场景：市占率/排名宣告，无具体奖项。

大纲：
1. 标题 + 副标题（突出核心数字）
2. 行业态势+品牌数据（第三方数据直接引出品牌表现）
3. 品牌核心优势拆解（技术/产品/渠道，各 1-2 句）
4. 代表产品简要介绍（1-2 款，每款 2-3 句）
5. 用户/媒体评价佐证（引用真实评价或媒体报道）
6. 品牌愿景收束

### 变体 C — 渠道合作表彰型

适用场景：合作方（京东/天猫等）授予年度合作伙伴等荣誉。

大纲：
1. 标题 + 副标题（突出合作方名称+奖项）
2. 行业趋势+品牌在该渠道的表现（数据+排名）
3. 渠道合作成果回顾（具体销售数据+营销活动亮点）
4. 奖项宣布（合作方授予的荣誉+授予理由）
5. 产品技术优势拆解（品牌为什么能在该渠道胜出，2-3 段）
6. 媒体/用户评价佐证
7. 品牌愿景收束

---

## 变体融合规则

- 数据+奖项型活动中也有渠道数据亮点 → A + C，将渠道段嵌入品牌表现之后
- 纯数据型活动中有奖项 → B + A，将奖项段作为数据佐证嵌入

## 产品介绍模板（喜报专用）

喜报产品介绍面向"数据/奖项佐证"场景，强调产品硬参数而非体验场景。核心思路：**产品是品牌数据的底牌**——数据证明品牌强，产品参数解释品牌为什么强。

**完整版**（核心产品深度，120-200 字）：
> 型号 + 产品定位 → 面板类型 + 尺寸 → 核心参数（分辨率+刷新率+背光分区+峰值亮度+色域）→ 独家技术（DyDs 等）→ 与奖项/数据的关联

示例：
> "作为泰坦军团 MiniLED 产品线的旗舰力作，P275MV MAX 搭载了超精细 QD-MiniLED 背光系统，配备多达 2304 个独立控光分区...在亮度表现上，该产品峰值亮度高达 1600 尼特，达到了 HDR1400 认证标准..."

**注意**：喜报的产品介绍不再加"品质收束句"（"这不仅展现了...更印证了..."），因为奖项本身已是品质证明。产品参数讲完直接进入下一段。

- [ ] 每段数据陈述紧跟品牌关联句（不裸奔）
- [ ] 产品介绍按技术点分段（一段一事）
- [ ] 产品段后不加品质收束句（喜报类型豁免）
- [ ] 全文无空洞形容词（"优秀的""卓越的"等）
- [ ] 结尾为品牌技术迭代方向/市场承诺，非展会 CTA
- [ ] 同一主张如已在其他喜报中出现，更换表达角度
- [ ] 技术参数待产品团队核实
- [ ] 全文无破折号
- [ ] 字数约 1200-1800 字
