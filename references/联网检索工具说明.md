# 联网检索工具说明

## 用途

PR 稿件创作中的信息核实与素材搜集。遇到不确定的产品参数、行业术语、合作方背景等信息时，先上网检索，多源交叉验证，找不到再问用户。

## 触发场景

- 产品型号的参数、技术规格不明确或需核实
- 合作伙伴/嘉宾的名称、背景、合作细节不清楚
- 行业术语、技术概念（如"AMD 千帧电竞""DyDs 2.0"等）需要准确理解
- 竞品信息、市场价格等需要参考

## 工具选择

| 场景 | 工具 | 说明 |
|------|------|------|
| 事实性信息（参数、名词、背景） | `WebSearch` | 覆盖面广，速度快，适合多源对比 |
| 需交互或登录态的页面（品牌官网产品页、电商详情页） | `web-access CDP` | 真实浏览器环境，支持动态渲染页面 |
| 社交媒体内容（小红书、微博等） | `web-access` | 需要真实浏览器环境 |

## 信息检索流程

1. **多渠道搜索**：针对同一信息点，从不同关键词、不同角度多次检索
2. **交叉验证**：至少对比 2-3 个独立来源，确认信息一致性后再采纳
3. **优先一手来源**：品牌官网、电商官方旗舰店、权威评测机构 ＞ 自媒体/论坛/二手转述

## 搜索后处理

- 将搜索结果汇总为简短要点，标注信息来源，作为写作素材
- 多源信息一致 → 直接采纳；信息矛盾 → 优先一手来源或再搜一轮
- 只有搜索确实找不到或结果严重矛盾时，才向用户确认
- 不要因为"不确定"就直接跳过——先搜，多验证，找不到再说
