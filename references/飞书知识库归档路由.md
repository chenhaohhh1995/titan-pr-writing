## 发布流程

1. 根据已确定的稿件类型，从上表取唯一 `parent_node_token`。不要按名称搜索目录。
2. 用用户身份在该分类下创建 Wiki 文档节点：

```bash
lark-cli wiki +node-create \
  --parent-node-token <PARENT_NODE_TOKEN> \
  --title "【标签】YYYYMMDD_品牌_事件_看点" \
  --obj-type docx \
  --as user \
  --format json
```

3. 保存返回的 `node_token` 和 `obj_token`。将终稿转换为 lark-doc XML；不要在正文中加入 `<title>`。
4. 向新节点写入正文：

```bash
lark-cli docs +update \
  --doc <OBJ_TOKEN> \
  --command append \
  --content '<p>XML 正文</p>' \
  --as user \
  --format json
```

5. 创建节点成功但正文写入失败时，停止并报告现有 `node_token`；禁止再次创建同名节点。修复后继续写入原节点。
6. 写入成功后，用 `wiki +node-get --node-token <NODE_TOKEN> --as user` 验证标题、父节点和 space_id。
7. 输出：

```text
✅ 稿件已写入飞书知识库：<分类名>
🔗 点击查看：https://xcnoiey1w9zw.feishu.cn/wiki/<NODE_TOKEN>
```
