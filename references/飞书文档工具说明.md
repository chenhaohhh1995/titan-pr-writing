# 飞书文档工具说明

## 用途

操作飞书云文档（知识库、文档、表格等）。PR 稿件创作中用于读取参考稿件、查阅知识库内容。

## 常用命令

### 读取知识库文档

```bash
# 从 wiki URL 获取文档 token
lark-cli wiki spaces get_node --params '{"token":"<wiki_token>"}' --format json

# 读取文档内容（Markdown 格式）
lark-cli docs +fetch --api-version v2 --doc "<doc_token>" --doc-format markdown --detail simple
```

### 读取文档目录（大纲探测）

```bash
lark-cli docs +fetch --api-version v2 --doc "<doc_token>" --scope outline --max-depth 3
```

### 按章节精读

```bash
lark-cli docs +fetch --api-version v2 --doc "<doc_token>" --scope section --start-block-id <标题id> --detail with-ids
```

### 创建文档（Markdown 格式，长文本推荐 `@文件` 传参）

```bash
# --content @文件路径 必须用相对路径，不能用绝对路径
cd "项目目录" && lark-cli docs +create --api-version v2 --doc-format markdown \
  --parent-token "<wiki_node_token>" --content "@相对路径/article.md"

# 短内容可直接内联
lark-cli docs +create --api-version v2 --doc-format markdown \
  --content $'# 标题\n\n正文内容'
```

### 编辑文档

```bash
# 追加内容
lark-cli docs +update --api-version v2 --doc "<doc_token>" --command append --content '<p>追加内容</p>'

# 覆盖全文
lark-cli docs +update --api-version v2 --doc "<doc_token>" --command overwrite --content '<title>新标题</title><p>新内容</p>'
```

## 踩坑记录

### `docs +create` 不支持 `--format json`

`+create` 默认输出 JSON，加 `--format json` 会报 `Error: unknown flag: --format`。`+fetch` 才需要 `--format json` 指定输出格式。

### `--content @文件` 必须是相对路径

传绝对路径（如 `C:/Users/...`）会报错：
> `--file must be a relative path within the current directory`

**正确做法**：先 `cd` 到文件所在父目录，再用相对路径引用。

### 长文本传参建议

文章内容长、含特殊字符时，用文件传参（`--content @相对路径`）绕开 shell 转义问题，不用 heredoc 或内联。

## 注意事项

- 飞书云文档默认只读不写，写操作前必须先向用户报计划确认
- 文档 content 返回中的图片 URL 可直接用于 HTTP 下载
- 遇到权限错误，根据 `--as bot` / `--as user` 身份选择对应的认证方式
